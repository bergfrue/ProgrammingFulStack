Technologies Used in My Project

XHTML

Even though there are some errors in the markup, any website will still display properly. In my XHTML page, I used elements such as <!DOCTYPE>, <html>, <head>, <title>, and <body>. All values inside the elements are properly quoted.

HTML5

Later pages used modern HTML5 syntax, semantic tags, and more flexible rules. My spam-detection interface and documentation pages were written in HTML5.

HTML5 Canvas Element

The <canvas> element has been used to draw graphics. The code includes height and width attributes to specify size.

HTML5 Video Element

I used HTML5 structural elements such as <article>, <aside>, <figure>, <header>, and <footer>. I also embedded video using the <video> element.

CSS

I used CSS to improve the appearance of the website by applying properties such as background-color, text direction, and display settings.

JavaScript

JavaScript was used on the client side to add interaction and functionality to my pages.

Dynamic JavaScript

Dynamic JavaScript updated the page without reloading. I used it to count characters for spam detection, handle button clicks, add event listeners, and hide HTML elements using style.display = "none".

PHP

When a visitor fills out the spam checker form and clicks the "check spam" button, the form data is sent for processing using the HTTP POST method.

Database

In my spam-detection database, the root segment is the main spam message entry. Related details such as classifications or logs act as child segments. A segment type represents a category like “message” or “classification,” while a segment occurrence is a single record. Multiple logs under the same message act as twin segments. These relationships organize how the database stores and connects information.

SVG Logo

I embedded an SVG logo and included both a smaller and a larger version of it.

Webserver

Apache was used as the webserver. MySQL and Apache both needed to be running (green indicators). Inside the htdocs folder, I created a project folder containing all my pages and code.

XHTML Validation

Validation was performed using the W3C validator.
